# Personal Budget Manager - Java

A simple console-based Java application to manage monthly budget and expenses.

## Features
- Add expenses with category, amount, date, and notes
- View all expenses
- View category-wise spending summary (Food, Rent, Transport, etc.)
- Set monthly budget and get over-budget alerts
- File persistence - data saved to expenses.txt

## Tech Stack
- Java
- OOP Concepts
- ArrayList, File I/O (FileWriter, Scanner)
- Console-based Menu System

## How to Run
1. Clone the repo
2. Compile: `javac BudgetManager.java`
3. Run: `java BudgetManager`
